    Learn the DFA behind the elevator

    A DFA reads inputs one at a time. In each state, each input leads to exactly one next state. Formally: M = (Q, Σ, δ, q₀, F)

    Q: states
    Each state combines a phase (IDLE, MOVING_UP, MOVING_DOWN, ARRIVED, DOOR_OPEN) with the floor, and while moving, the destination: for example MOVING_UP[1→3]. With 6 floors that gives states, so the model really is finite.
    Σ: alphabet
    symbols: SELECT_0 to SELECT_5, FLOOR_REACHED (sensor sees the next floor), OPEN_DOOR, CLOSE_DOOR.
    δ: transition function
    A lookup table from (state, symbol) to the next state. Inputs that make no sense in a state, like opening doors while moving, send the DFA back to the same state (a self-loop), so δ is defined everywhere.
    q₀: initial state
    IDLE[0]: the car waits at the ground floor with no request.
    F: accepting states
    All DOOR_OPEN[f] states. An input string is accepted if it ends with the doors open at a stopped floor, which is how a valid trip ends. Other operational states (moving, idle) are not accepting.

    Abstraction: real elevators have more floors, queued requests and weight sensors. This model serves one request at a time.
